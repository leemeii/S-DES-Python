# S-DES 算法实现

使用 Python 和 Tkinter，实现作业要求的加解密、ASCII 字符串处理、暴力破解和第五关碰撞分析。按三人一组准备，关键算法步骤、界面调度和测试目的均配有简短注释。

## 运行

使用带有 Tkinter 的 Python 3.9 或更高版本，不需要安装第三方库。

Windows 下双击 `启动程序.bat`，也可以在本文件夹的终端运行：

```text
python app.py
```

如果系统无法识别 `python`，但安装了 Python 启动器，可以使用 `py app.py`。如果出现 `No module named tkinter`，请在 Python 安装程序中启用 Tcl/Tk 组件。

运行自动测试：

```text
python test_sdes.py
```

## 用户指南

### 加密与解密

选择“二进制（8 位）”，输入 8 位数据和 10 位密钥，点击“加密”或“解密”。结果下方显示两个子密钥。点击“结果填回输入”可以继续验证解密是否还原原文。

选择“ASCII 字符串”，加密时输入英文、数字等 ASCII 原文。程序保留空格、换行和制表符。解密时输入十六进制密文，每两个十六进制数字代表一个字节，可以用空格分隔。中文、表情等非 ASCII 字符会提示输入错误。

每个字符独立作为一个 8 位分组处理，无填充。加密后的字节可能无法直接显示，所以界面采用可复制的十六进制表示。该表示只影响显示，不改变密文。

### 暴力破解

每行输入一组“8 位明文 空格 8 位密文”。点击“遍历 1024 个密钥”，程序会显示进度、耗时和所有满足输入条件的密钥。可以输入多组明密文对进一步筛选，也可以中途停止。停止后的列表是不完整结果。

界面分别记录搜索计算时间和包含界面调度的总时间。密钥空间很小，因此未使用多线程。

### 碰撞分析（第 5 关）

输入任意 8 位明文，点击“分析全部密钥”。程序统计全部 1024 个密钥产生的密文，列出不同密钥得到同一密文的分组。这里按作业第五关的具体问题分析密钥碰撞，不把它解释为数学上的密码族复合封闭性检验。

## 算法约定

参数采用作业 PDF 中的 P10、P8、IP、逆 IP、EP、SP 和两个 S 盒，包含 PDF 修改过的第二个 S 盒。

密钥扩展按 PDF 公式 `ki = P8(Shift^i(P10(K)))` 的字面定义实现：P10 后拆成两个 5 位部分，K1 从这两个原始部分分别循环左移 1 位得到，K2 从这两个原始部分分别循环左移 2 位得到。

这个约定下，K2 相对 P10 结果共左移 2 位。它与常见 S-DES 中“先左移 1 位，再在前一次结果上左移 2 位（累计 3 位）”的规则不同。PPT 的移位流程图没有明确第二阶段的位数，因此跨组互测时必须先核对该约定；若老师确认要求累计 3 位，需要统一修改密钥扩展并重跑测试，不能混用测试向量。

加密流程为 IP、第一轮、左右交换、第二轮、逆 IP。解密复用同一流程，子密钥顺序反转。S 盒使用 4 位输入的首尾两位作为行号，中间两位作为列号。

在本程序采用的移位规则下，原密钥从左数第 2 位不影响两个子密钥，所以会出现等效密钥。即使提供所有明密文对，也不一定能唯一确定原密钥。程序会完整返回这些候选密钥。

## 开发说明

| 文件 | 用途 |
| --- | --- |
| `sdes.py` | 算法、字符串处理、候选密钥搜索、碰撞分组 |
| `app.py` | 三个页面的 Tkinter 界面 |
| `test_sdes.py` | 穷举测试、独立字符串实现核对、错误输入测试 |
| `cross_test_cases.json` | 供其他组核对的算法约定和测试向量 |
| `测试结果.md` | 五关验证结果及跨组测试待办 |
| `测试日志.txt` | 本机自动测试运行日志 |
| `启动程序.bat` | Windows 启动入口 |

主要接口：

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `subkeys(key)` | 整数密钥 0–1023 | 两个 8 位整数子密钥 |
| `encrypt(block, key)` | 整数分组 0–255、整数密钥 | 整数密文 0–255 |
| `decrypt(block, key)` | 整数密文 0–255、整数密钥 | 整数明文 0–255 |
| `encrypt_text(text, key)` | ASCII 字符串、整数密钥 | 十六进制密文字符串 |
| `decrypt_text(ciphertext, key)` | 十六进制密文字符串、整数密钥 | ASCII 原文 |
| `find_keys(pairs)` | `(明文整数, 密文整数)` 的非空列表 | 所有符合条件的整数密钥 |
| `collision_groups(plain)` | 整数明文 0–255 | `{密文: [密钥, ...]}` |

输入不合法时抛出 `ValueError`，界面将其显示为错误提示。变量和函数采用 snake_case 命名，重复逻辑集中在算法模块。
